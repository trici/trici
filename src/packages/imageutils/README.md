# `@trici/imageutils`

Utilities related to image comparison. May add other functions later on. Basically it has sharp(a native node module) as a dependency so migrated this code away from utils. In this way, sharp as a dependency is not required by other packages where utils is used. Also, do not have to mark sharp as an external dependency in those cases.
